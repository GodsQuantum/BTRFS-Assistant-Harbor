# ⚓ Btrfs Assistant Harbor — press kit

**Product:** Btrfs Assistant Harbor

**Tagline:** Snapshots in. Systems back.

**One-line pitch:** Keep the Btrfs Assistant you know. Turn local Snapper snapshots into verified, off-device Linux backups.

**Short description:** Native Qt 6 Btrfs/Snapper desktop fork with a Rust content-addressed backup engine, full/incremental transfer, machine-aware shared CAS, verification and safe staged recovery.

**Supported:** Linux x86-64, Btrfs + Snapper. Tested native packages: Debian 13, Fedora 44 and Arch/CachyOS. Network destructive GC, macOS/APFS and encrypted/multi-root ReaR are excluded.
